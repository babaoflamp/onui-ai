## 📊 1. 현황 요약 (5분)

### 사용 중인 AI 시스템

| AI 모델 | 용도 | 비용 |
|---------|------|------|
| **Ollama (EXAONE 3.5)** | 대화문/어휘 생성, 챗봇 | 무료 (로컬) |
| **Google Gemini** | 대화문/어휘 생성 (대체) | 저렴 ($0.001/1K) |

### 주요 기능 (6개 엔드포인트)

1. **대화문+어휘 생성** - 주제/레벨별 학습 컨텐츠
2. **상황별 컨텐츠** - 카페/식당/병원 등 6가지 상황
3. **작문 교정** - 유창성 평가 + 피드백
4. **챗봇 튜터** - 실시간 질의응답
5. **이미지 생성** - 상황별 일러스트 (12가지 스타일)
6. **테스트** - 모델 성능 확인

## ✅ 2. 잘 되고 있는 점 (5분)

### 강점

1. ✅ **다중 백엔드** - Ollama/Gemini 선택 가능 (비용/품질 균형)
2. ✅ **레벨별 맞춤** - 초급/중급/고급 난이도 자동 조절
3. ✅ **JSON 구조화** - 모든 AI 출력을 JSON 형식으로 강제
4. ✅ **로마자화** - 한국어 발음을 영어로 자동 변환 (학습자 친화)
5. ✅ **스타일 다양성** - 수채화, 일러스트, 만화 등 12가지 이미지 스타일

### 프롬프트 예시 (대화문 생성)

```
한국어 선생님입니다.
주제: '카페'
레벨: '초급'

짧고 간단하게, 쉬운 어휘를 사용하세요.

대화문(3~4마디)과 단어 3개를 JSON으로 만들어주세요.
형식: {"dialogue": [...], "vocabulary": [...]}
```

**결과**:
```json
{
  "dialogue": [
    {"speaker": "A", "text": "무엇을 드릴까요?", "pronunciation": "mueoseul deurilkkayo?"},
    {"speaker": "B", "text": "아메리카노 주세요.", "pronunciation": "amerikano juseyo."}
  ],
  "vocabulary": ["아메리카노", "주세요", "커피"]
}
```

## ⚠️ 3. 개선 필요한 부분 (10분)

### 문제점

| 문제 | 현재 상황 | 영향 |
|------|----------|------|
| **Few-shot 예시 없음** | 프롬프트에 예시 미제공 | JSON 파싱 실패율 30% |
| **평가 기준 모호** | "자연스러움" 한 가지만 평가 | 학습 효과 낮음 |
| **대화 맥락 부재** | 이전 대화 기억 안함 | "그거 뭐야?" 질문 불가 |
| **한국어 직접 전달** | DALL-E에 한국어 프롬프트 | 이미지 품질 저하 |

### 개선 제안 (우선순위별)

#### 🔴 긴급 (1주일 내)

**1. Few-shot 예시 추가**

```python
# Before (현재)
"대화문과 어휘를 JSON으로 만들어주세요."

# After (개선)
"대화문과 어휘를 JSON으로 만들어주세요.

예시:
```json
{
  "dialogue": [
    {"speaker": "A", "text": "안녕하세요", "pronunciation": "annyeonghaseyo"}
  ],
  "vocabulary": ["안녕하세요"]
}
```

위 형식으로 작성하세요."
```

**효과**: 파싱 성공률 70% → 95%

---

**2. 평가 프롬프트 개선**

```python
# Before (현재)
"이 문장의 자연스러움을 100점으로 평가하고 피드백 주세요."

# After (개선)
"다음 기준으로 평가하세요:
1. 문법 정확성 (0-100)
2. 어휘 적절성 (0-100)
3. 자연스러움 (0-100)

JSON 형식:
{
  "scores": {"grammar": 85, "vocabulary": 90, "fluency": 80},
  "corrected": "교정된 문장",
  "errors": [
    {"type": "문법", "original": "~을", "corrected": "~를", "explanation": "이유"}
  ],
  "feedback": "전체 피드백"
}
```

**효과**: 학습 효과 향상, 구체적 오류 설명

---

#### 🟡 중요 (2주일 내)

**3. 챗봇 대화 이력 관리**

```python
# Before (현재)
prompt = "질문: {user_message}"  # 단일 질문만

# After (개선)
conversation_history = [
  {"role": "user", "content": "안녕하세요"},
  {"role": "assistant", "content": "안녕하세요! 무엇을 도와드릴까요?"},
  {"role": "user", "content": "그거 뭐야?"}  # "그거" 이해 가능
]

prompt = f"""
이전 대화:
{conversation_history}

현재 질문: {user_message}
"""
```

**효과**: 자연스러운 대화 흐름

---

**4. DALL-E 프롬프트 번역**

```python
# Before (현재)
situation = "서울의 전통 시장"  # 한국어 그대로
enhanced_prompt = f"{situation}, watercolor style, ..."

# After (개선)
english = translate_to_english(situation)  # Gemini 번역
# → "A vibrant traditional Korean market in Seoul"
enhanced_prompt = f"{english}, watercolor style, ..."
```

**효과**: 이미지 품질 향상, 재생성 감소
