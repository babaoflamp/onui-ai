### 🔐 **E. 보안 및 인증 강화**

**목적**: 사용자 데이터 보호 및 신뢰성 향상

**제안 기능**:
1. **비밀번호 보안**
   - SHA-256 → bcrypt 전환
   - 비밀번호 강도 검사
   - 비밀번호 복구 (이메일 인증)

2. **2단계 인증 (2FA)**
   - TOTP 기반 (Google Authenticator)
   - SMS 인증 (선택적)

3. **소셜 로그인**
   - Google OAuth 2.0
   - Kakao 로그인
   - Naver 로그인

4. **세션 관리**
   - JWT 토큰 만료 시간 설정
   - 리프레시 토큰
   - 다중 기기 로그인 관리

5. **보안 로깅**
   - 로그인 실패 추적
   - IP 기반 차단
   - 의심스러운 활동 알림

**기술 스택**:
- 비밀번호: bcrypt, passlib
- JWT: python-jose
- OAuth: authlib
- 2FA: pyotp

**개발 일정 제안**:
- 1주차: bcrypt 전환 + 비밀번호 복구
- 2주차: 소셜 로그인
- 3주차: 2FA + 세션 관리

**목적**: 모바일 사용자 경험 최적화

**제안 옵션**:

1. **PWA (Progressive Web App)**
   - 현재 웹 기반 유지
   - 오프라인 지원
   - 홈 화면 추가 가능
   - 푸시 알림
   - **장점**: 빠른 개발, 코드 재사용
   - **단점**: 네이티브 기능 제한

   - 크로스 플랫폼 앱
   - iOS + Android 동시 개발
   - **장점**: 네이티브 성능, 풍부한 기능
   - **단점**: 개발 시간 증가

3. **네이티브 앱**
   - Swift (iOS) + Kotlin (Android)
   - **장점**: 최고 성능, 모든 기능 접근
   - **단점**: 2배 개발 시간

**권장**: **PWA** (현재 리소스 고려)

**개발 일정 제안**:
- 2주차: PWA manifest + Service Worker
- 4주차: 오프라인 지원
- 6주차: 푸시 알림 연동
