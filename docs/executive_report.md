# 오누이 한국어 – 경영진 브리핑

## 비전과 가치
- **미션**: 맞춤 지침, 인터랙티브 게임, 문화 몰입을 결합한 AI 기반 한국어 학습 동반자를 제공해 학습 효율을 극대화합니다.
- **가치 제안**: SpeechPro·FluencyPro 발음 평가, 생성형 AI 교재 제작, 데이터 기반 학습 진도 추적을 결합해 B2C·기관 고객 모두의 온보딩 기간을 단축하고 유지율을 향상시킵니다.
- **전략적 적합성**: Mediazen의 음성 기술 자산과 국내 인프라 준수를 활용해 로컬라이즈된 AI 학습 경험을 제공하는 프리미엄 브랜드로 포지셔닝합니다.

## 고객 경험 스냅샷
| 학습 여정 축 | 핵심 기능 | 비즈니스 임팩트 |
| --- | --- | --- |
| 발음 마스터리 | 발음 정확도 테스트(`/speechpro-practice`), 단계별 드릴, 로마자 가이드, 규칙 학습. | 정량 개선을 제시해 인증형 업셀을 열고 차별화. |
| AI 튜터 & 콘텐츠 | 프롬프트형 학습 코치(`/learning`), 맞춤 교재, 유창성 테스트, 상황별 콘텐츠, 챗봇. | 커리큘럼 제작을 자동화해 전문가 리소스를 절약하고 B2B 맞춤 제안을 가능하게 함. |

| 러너 포털 | 마이페이지 대시보드, 학습 진도 분석, 팝업 코칭 캐릭터. | 맞춤 보상과 진행 알림으로 유료 전환을 유도. |

## 시스템 아키텍처 개요 (슬라이드 용)
- **계층 구조**
  - **프레젠테이션**: Jinja2 + Tailwind 템플릿, 모듈형 내비게이션(소비자/관리자/랜딩)과 WebAudio·MediaRecorder 프론트 스크립트.
  - **서비스/API**: FastAPI 단일 앱(`main.py`)이 REST/페이지 라우트, CORS, 정적 자산 제공을 통합 관리.
  - **데이터/콘텐츠**: JSON 카탈로그(어휘·문장·전래동화·문화 표현·SpeechPro 질문) + SQLite(`data/users.db`)가 학습 진도, 팝업, 세션 로그를 저장.

## 사용 언어 & 프레임워크
- **Python 3.10+**: FastAPI, asyncio, sqlite3, requests, pydantic 기반의 서버 및 서비스 계층.
- **Jinja2 / Tailwind CSS / Vanilla JS**: 서버 렌더 템플릿과 상호작용 UI.
- **Shell**: systemd 서비스 스크립트, ngrok/cloudflared 터널, 배포 자동화.

## 핵심 기술 스택
| 영역 | 기술 | 활용 포인트 |
| --- | --- | --- |
| 음성 평가 | SpeechPro API 래퍼, FluencyPro WebSocket, VOSK(옵션) | 문자→음소 GTP, FST 모델 생성, 실시간 PCM 분석 |
| 생성형 AI | Ollama(EXAONE), OpenAI, Gemini, Prompt Enhancement 유틸 | LLM 백엔드 스위칭, 맞춤 교재/챗봇/콘텐츠 생성 |
| 음성 합성 | Mediazen TTS(MzTTS) | 발음 훈련·게임 내 고품질 한국어 음성 출력 |
| 데이터 관리 | SQLite, JSON 데이터셋, LearningProgressService | 학습 통계, 팝업 히스토리, 메타데이터 일원화 |
| DevOps | systemd, start/stop 스크립트, ngrok/cloudflared, uploads 파이프라인 | 온프레/원격 배포 자동화 및 미디어 저장 |

## 보안 및 준수 (슬라이드 핵심)
- `.env` 기반 비밀 관리, 옵션형 OpenAI/Gemini 키 분리.
- Ollama·VOSK·온프레 Speech/TTS로 로컬 처리 선호 → 데이터 국외 이전 회피.
- 인증 API(`/api/signup`, `/api/login`, `/api/user/*`)에서 해시/HMAC 적용, 활동 로그 기반 감사 준비.

## 성능·관측 포인트
- LearningProgressService로 시간·점수·배지 지표 집계 → 대시보드/알림 연동.
- `/api/log/*` 엔드포인트로 게스트→정식 사용자 여정 데이터 확보.
- `tests/api|integration|unit` 폴더 구조를 통해 향후 CI 파이프라인 연결 용이.

## KPI 기회 영역
1. **획득**: 랜딩 인입 대비 게스트 로그인 비율을 추적해 유료 광고 효율 최적화.
2. **활성화**: SpeechPro 완료율과 세션 간 평균 점수 향상 지표 측정.
3. **참여**: 게임·문화 모듈의 일/주간 활성 사용자와 배지 발급 상관관계 모니터링.
4. **수익화**: `/mypage` 기반 무료 학습자의 프리미엄 전환율 추적.
5. **유지**: 연속 학습 일수와 팝업 트리거 재방문 세션을 계량화.
